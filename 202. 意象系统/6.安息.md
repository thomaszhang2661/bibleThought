# 安息：从起初到末了的一条线

## 一、"安息"这个词是什么意思

"安息日"的希伯来文是 _Shabbat_（沙巴特），字面意思是"停下来""不再做了"，不是"累了要休息"。

这一点很重要，因为圣经第一次讲安息时，讲的是神。全能的神当然不会累，他的"安息"意思是：工作完成了，一切都好，他停下来欣赏、享受自己所做的。

## 二、起源：创造的第七天

圣经开头讲神用六天创造世界：光、天空、海洋陆地、植物、日月星辰、鱼鸟、动物，最后是人。每一天结束时都有一句话："有晚上，有早晨，是第几日。"

到了第七天，圣经说神"歇了他一切的工"，并且赐福给这一天，把它定为圣日（创2:1-3）。

这里有两个容易忽略的细节。

第一，**人是在第六天被造的。** 人醒来后过的第一个完整的日子，就是安息日。人还什么都没做，就先被邀请进入神的安息。安息不是人干完活挣来的奖赏，而是神先预备好、白白给人的礼物。

第二，**第七天没有"有晚上，有早晨"。** 前六天都有结尾，唯独第七天没有。许多读经的人认为这在暗示：神本来要人一直活在这种安息里，没有终结。

## 三、安息失去了

人没有一直留在那里。亚当夏娃不信靠神，偷吃禁果，后果之一就是劳苦。神对亚当说，你必"汗流满面才得糊口"（创3:17-19）。工作本身不是咒诅，但从此工作变成了重担，人开始累，开始焦虑，停不下来。

从这以后，整本圣经都在讲一件事：人怎样重新得到安息。

一个很早的线索在挪亚身上。挪亚出生时，他父亲给他起这个名字，盼望"这个儿子必为我们的劳苦安慰我们"（创5:29）。"挪亚"这个名字听起来就像希伯来文的"安息"。洪水过后，方舟"停"在山上，用的是同一个字根。人从一开始就在盼望有人带来安息。

## 四、图画一：从奴隶到自由人

以色列人在埃及做了四百年奴隶。奴隶没有休息日，被逼着每天做砖、建城，一天都不能停。

神救他们出来以后，在旷野每天从天上降下食物，叫"吗哪"。规矩很特别：每天只收一天的量，多收会臭；但第六天可以收两天的量，第七天不降，也不用出去收（出16章）。

这是一堂实物课。以前在埃及，停一天就会挨打；现在神说，停下来吧，我会供应你。安息的本质是**信任**：相信就算我不干活，神也会养活我。

后来神颁布十诫，其中一条就是守安息日。申命记给出的理由很动人："你也要记念你在埃及地作过奴仆，耶和华你的神用大能的手将你从那里领出来"（申5:15）。意思是：你现在不是奴隶了，自由人才能休息。而且这条诫命连仆人、牲口、外地人都包括在内，没有人应该被逼着一直干活。

## 五、图画二：安息被放大

神不只定了每周一天的安息，还把它放大。

**安息年。** 每到第七年，土地要休耕一年，地里自己长出来的东西，穷人和野兽都可以吃。这一年还要免除欠债，释放做奴仆的同胞（利25章；申15章）。土地也要"守安息"。

**禧年。** 七个安息年就是四十九年，第五十年叫"禧年"，这是整个制度的高潮。这一年在赎罪日吹响号角，宣告"自由"。被卖为奴的回家，因为贫穷卖掉的祖传土地归还原主（利25:8-17）。

可以想象这个画面：一个人年轻时家道中落，卖了地，甚至卖了自己。他以为这辈子就这样了。忽然有一天号角响起，债一笔勾销，他可以走回家，站在祖父留下的那块地上。这就是禧年，一切重新开始。

马太福音的家谱也许就在暗示这个。它把耶稣以前的历史分成三段，每段十四代，共四十二代，也就是六个"七"。耶稣出生，正好开启第七个"七"。这个解读不是马太明说的，但很符合犹太人用"七"看历史的习惯。

## 六、图画三：应许之地，却不完全

以色列人在旷野流浪四十年，目标是进入"应许之地"迦南。圣经常把进入这块地称为"进入安息"。那是一个有家、有地、不再漂泊、不被敌人追赶的地方。

但进了迦南以后，问题并没有结束。百姓一再背离神，打仗、失败，最后被掳到巴比伦。圣经说他们在外七十年，正好让土地补足那些他们没守的安息年（代下36:21）。

诗篇95篇有一句很沉重的话，神说："他们断不可进入我的安息。"这说明真正的安息不只是一块土地，还有更深的东西。

## 七、耶稣：安息本人来了

到了新约，耶稣说了一句很有名的话：

> 凡劳苦担重担的人，可以到我这里来，我就使你们得安息。（太11:28）

他不是说"我教你们怎样安息"，而是说"到我这里来"。安息就是他自己。

福音书里有很多耶稣在安息日的故事，他常常故意在安息日医治人。当时的宗教领袖为此很生气，觉得医治也是"工作"。耶稣的回答是："安息日是为人设立的，人不是为安息日设立的"（可2:27）。

有一个故事特别清楚。一个女人弯腰驼背十八年，耶稣在安息日医好她，并说她被撒但"捆绑"了十八年，"不当在安息日解开她的绑吗？"（路13:16）。这就是禧年的语言：释放被捆绑的人。耶稣在家乡的会堂第一次公开讲道，也是在安息日，读的正是关于"释放"和"禧年"的经文，然后说："今天这经应验了"（路4:16-21）。

## 八、最深的一幅图画：坟墓里的安息

耶稣在星期五被钉十字架，傍晚下葬。第二天，星期六，正是安息日。

那一整天，耶稣的身体躺在坟墓里。就像神在第七天歇了创造之工，耶稣在第七天歇了救赎之工。他在十字架上说过："成了。"工作完成了，他安息了。

然后在"七日的第一日"，也就是星期天的清晨，他复活了。在七之后的第一天，就像禧年在七个七之后到来。这是一个全新的开始，一个新的创造。这就是为什么基督徒后来在星期天聚会，称它为"主日"。

## 九、还没有完全到来的安息

新约的希伯来书专门讨论了这个主题。它说，约书亚带以色列人进迦南，并没有给他们真正的安息，所以"必另有一安息日的安息，为神的子民存留"（来4:9）。

怎样进入这安息？书里说："已经进入安息的，乃是歇了自己的工，正如神歇了他的工一样"（来4:10）。意思是不再靠自己努力去讨神喜欢，不再证明自己够好，而是信靠耶稣已经完成的工作。

圣经最后一卷书启示录说，那些在主里死去的人"歇了自己的劳苦"（启14:13）。那时第七天将再次没有结尾。

## 十、把整条线连起来

| 阶段         | 发生了什么                                                 |
| ------------ | ---------------------------------------------------------- |
| 起初         | 神完成创造，安息，并邀请人一同享受                         |
| 失落         | 人背离神，从此劳苦不息                                     |
| 出埃及       | 神救奴隶出来，用每周的安息日提醒他们：你是自由人，我供应你 |
| 安息年与禧年 | 安息被放大：债务免除，奴仆释放，产业归还                   |
| 应许之地     | 一个不完全的安息，让人盼望更深的东西                       |
| 耶稣         | "到我这里来，我就使你们得安息"；他在安息日医治、释放人     |
| 十字架与复活 | 他在安息日躺在坟墓里，在第一日复活，开启新创造             |
| 末了         | 完全的安息，永远没有晚上                                   |

如果用一句话总结：**安息不是人做到的，而是神给的；它的终点不是一个日子，而是一个人——耶稣。**

如果你想往下读，建议从这三处开始：创世记1-2章（起源）、马太福音11:28-12:14（耶稣与安息日），以及希伯来书3-4章（安息的完整意义）。
