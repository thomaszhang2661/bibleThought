# 一年三次朝见神：旧约三大节期的来历、农事与应验

我们现在用公历过日子，一年的节奏由元旦、春节、开学、年终这些日子划分。古代以色列人的一年也有节奏，最重要的三个节点就是神亲自设立的三大节期。

神吩咐以色列人："一年三次，你们所有的男丁要在耶和华你神所选择的地方朝见他，就是除酵节、七七节、住棚节"（申16:16）。这三个节期都要上耶路撒冷，所以又叫"朝圣节期"。耶稣十二岁那年随父母上耶路撒冷过逾越节（路2:41-42），五旬节那天耶路撒冷聚集了"从天下各国来的"犹太人（徒2:5），都是因为这条吩咐。

要理解这三个节期，需要同时看三样东西：历法、农事、救恩历史。神把这三者编织在一起，到了新约，又在耶稣身上把它们完成。

## 一、先看历法：为什么每年日期都不一样

旧约用的是阴阳合历。月份跟着月亮走，每月初一是新月，十五是满月；但一年又要跟着太阳和季节走，因为节期绑定在收成上。阴历一年比太阳年少约十一天，所以大约每三年要加一个闰月，否则节期会慢慢跑到错误的季节。

神在出埃及时定下："你们要以本月为正月，为一年的第一个月"（出12:2）。这个月叫"亚笔月"（出13:4），"亚笔"的意思是"青穗"，也就是大麦刚抽穗的时候。被掳以后改用巴比伦月名，叫"尼散月"（尼2:1）。所以以色列的宗教年是从春天开始的。

三大节期大致对应的公历如下：

| 节期             | 犹太历日期                                   | 大约公历            | 当季农事                 |
| ---------------- | -------------------------------------------- | ------------------- | ------------------------ |
| 逾越节、除酵节   | 正月（尼散月）十四日黄昏起，至二十一日       | 3月底至4月下旬      | 大麦开始收割             |
| 七七节（五旬节） | 从初熟节数五十天，约三月（西弯月）初六       | 5月中旬至6月中旬    | 小麦收割完毕             |
| 住棚节           | 七月（提斯利月）十五日至二十一日，另加第八日 | 9月下旬至10月中下旬 | 葡萄、橄榄、果子全部收藏 |

以今年为例：2026年的住棚节从9月25日傍晚开始，到10月2日结束，第二天就是第八日的"严肃会"。

我们今天的教会年历仍然带着这套历法的痕迹。复活节是"春分后第一个满月之后的第一个主日"，这个算法本身就源于逾越节的日期，因为耶稣是在逾越节期间受死复活的。教会的圣灵降临节在复活节后第五十天，直接继承了七七节。两套历法的闰月规则不同，所以复活节和逾越节有时很接近，有时相差将近一个月。2027年就是例子：西方教会的复活节在3月28日，而逾越节因为犹太历的闰月，要到4月下旬。

## 二、逾越节、除酵节、初熟节：春天，大麦，出埃及

### 一个节期，三个名称

读圣经时常会遇到三个名称：逾越节、除酵节、初熟节。它们不是三个分开的节日，而是春天连在一起的一组日子（利23:5-14）：

| 名称   | 日期                           | 做什么                   |
| ------ | ------------------------------ | ------------------------ |
| 逾越节 | 正月十四日黄昏                 | 宰羊羔，当夜吃逾越节的筵席 |
| 除酵节 | 紧接着的七天（十五至二十一日） | 只吃无酵饼，家中不可有酵 |
| 初熟节 | 除酵节期间"安息日的次日"       | 把第一捆大麦献给神       |

犹太人的一天从日落开始。羊羔在十四日下午宰杀，日落后进入十五日，所以逾越节的筵席也就是除酵节的第一餐，两者是无缝衔接的。到了耶稣时代，人们已经习惯把这整段日子统称为一个节期。路加福音说："除酵节，又名逾越节，近了"（路22:1）。这就像我们说"过年"，可以指除夕那一晚，也可以指整个春节。

这三个名称，讲的是同一次拯救的三个面向：逾越节是血的遮盖，除酵节是离开旧生活，初熟节是新生命的开始。下面分别来看。

农事背景

以色列的雨季在冬天。到了三四月，"春雨"（圣经叫"晚雨"）快结束，大麦最先成熟。

在除酵节期间，神吩咐要把第一捆收割的大麦拿到祭司那里，在耶和华面前摇一摇（利23:9-14），这就是初熟节。在献上这一捆之前，任何新粮都不可以吃。意思很简单：整个收成都是神给的，第一份先归给他，而且第一捆献上，就意味着后面整片庄稼都要收割。

救恩历史

这个节期纪念的是以色列人离开埃及的那一夜（出12章）。神要击杀埃及全地的长子，吩咐以色列每家宰一只没有残疾的羊羔，把血涂在门框和门楣上。神看见血，就"越过"那家，所以叫"逾越节"。

那一夜他们走得很匆忙，面团还来不及发酵，所以接下来七天只吃无酵饼。申命记称它为"困苦的饼"，"使你一生的日子记念你从埃及地出来的日子"（申16:3）。无酵饼提醒他们：你已经和埃及的奴役生活一刀两断了。

在新约的应验

这是三大节期中新约讲得最明白的一个，而且三个部分都有对应。

逾越节：羔羊被杀。 施洗约翰第一次见到耶稣就说："看哪，神的羔羊，除去世人罪孽的！"（约1:29）耶稣受死正是在逾越节期间。他和门徒吃的最后晚餐就是逾越节的筵席，他拿起饼和杯说"这是我的身体""这是我的血"（太26:26-28）。约翰福音记载兵丁没有打断耶稣的腿，并说这应验了"他的骨头一根也不可折断"（约19:36），引的正是逾越节羊羔的条例（出12:46）。保罗说得最直接："我们逾越节的羊羔基督，已经被杀献祭了"（林前5:7）。

除酵节：除去旧酵。 保罗紧接着说："你们既是无酵的面，应当把旧酵除净……就是除去恶毒、邪恶的酵，用诚实真正的无酵饼"（林前5:7-8）。次序很重要：先是羊羔被杀，然后才是除酵。不是我们先把自己清理干净，神才救我们；而是羔羊的血已经救了我们，所以我们过一个新的生活。

初熟节：初熟的果子。 耶稣在除酵节期间、"七日的第一日"复活。保罗写道："基督已经从死里复活，成为睡了之人初熟的果子"（林前15:20）。第一捆麦子献上，后面的收割必然跟着来；基督先复活，属他的人将来也必复活。（古代犹太人对"安息日的次日"具体指哪一天有不同理解，所以耶稣复活日是否刚好就是献禾捆的那一天，不能说得太死；但"基督是初熟的果子"这个对应，是圣经自己给的。）

对我们来说，逾越节最直接的延续就是圣餐。耶稣在逾越节的筵席上设立圣餐，在那里他亲自把真身体和宝血赐给我们，作为罪得赦免的凭据。当年以色列人吃羊羔、在血的遮盖下得救；今天我们领受的是羔羊本身。

## 三、七七节：初夏，小麦，丰收的喜乐

### 农事背景

从献初熟大麦那天开始数，"要满了七个安息日"，到第五十天就是七七节（利23:15-16）。希腊文的"第五十"就是 _Pentecost_，所以新约称它为"五旬节"。

这七个星期正是收割季节：先收大麦，再收小麦。到七七节，小麦收割完毕。出埃及记称它为"收割节"（出23:16），这一天要献上用新麦子做的两个饼（利23:17）。逾越节献的是一捆刚割下的麦穗，七七节献的是做好的饼，象征整个收成已经完成，成了人可以吃的食物。

路得记的故事正好发生在这七个星期里：路得和拿俄米"在动手割大麦的时候"回到伯利恒（得1:22），路得在波阿斯的田里拾穗，一直到"收完了大麦和小麦"（得2:23）。所以犹太人后来有在七七节读路得记的传统。

### 救恩历史与律法要求

旧约没有给七七节附加一个出埃及式的历史事件。它的重点是喜乐和慷慨。神吩咐："你和你儿女、仆婢……并在你们中间寄居的与孤儿寡妇，都要在耶和华你神面前欢乐"（申16:11）。紧接着又说："你也要记念你在埃及作过奴仆"（申16:12）。收割时不可割尽田角，要留给穷人和寄居的（利23:22），路得能拾穗，靠的就是这条律法。

后来的犹太传统把七七节和西奈山颁布律法联系在一起，因为以色列人是在出埃及后的第三个月到达西奈山的（出19:1）。这个关联是后来的传统，旧约本身没有明说，所以只能作为背景了解。

### 在新约的应验

耶稣复活后第五十天，正是七七节。"五旬节到了，门徒都聚集在一处"（徒2:1），圣灵降临。

时间点本身已经说明了许多。逾越节羊羔被杀，初熟节基督复活，五旬节收割开始。那一天，从各国来过节的犹太人听见门徒用他们各自的乡谈说话，彼得讲道之后，"那一天门徒约添了三千人"（徒2:41）。这是福音的第一次大收割。

新约也直接把圣灵和"初熟的果子"联系起来。保罗说我们这"有圣灵初结果子的"，正在等候身体得赎（罗8:23）；雅各说神用真道生了我们，"叫我们在他所造的万物中好像初熟的果子"（雅1:18）。

## 四、住棚节：秋天，收藏，住在帐棚里

### 农事背景

住棚节在七月，是一年农事的结尾。这时葡萄已经榨酒，橄榄已经榨油，果子都已收进仓里，所以它又叫"收藏节"（出23:16）。紧接着就要等秋雨，开始新一年的耕种。

这是三个节期中最欢乐的一个。神说："你要守节七日……你要欢欢喜喜地守节"（申16:15）。节期中要拿美好树上的果子、棕树枝、茂密树枝和河旁的柳枝，在神面前欢乐七日（利23:40）。

### 救恩历史

节期中，以色列人要离开房子，在临时搭的棚子里住七天。神说明了原因："好叫你们世世代代知道，我领以色列民出埃及地的时候，曾使他们住在棚里"（利23:42-43）。

想象一下这个画面：一个农夫刚把一整年的收成收进仓里，粮满仓、酒满缸，正是最有安全感的时候。神却叫他搬到一个漏风的棚子里住一个星期，提醒他：你的祖先在旷野四十年，没有房子，没有田地，全靠我每天供应。你的安全从来不在仓里。

更要紧的是，在旷野的四十年里，神自己也"住帐棚"。会幕就是一个大帐棚，神的荣耀住在其中，和百姓一起走在旷野里（出25:8；40:34-38）。住棚节记念的不只是人住过帐棚，更是神曾经住在他们中间。

住棚节在旧约历史中多次出现在关键时刻。所罗门献殿，正是在七月的节期（王上8:2），神的荣耀充满了殿。被掳归回后，以斯拉宣读律法，百姓重新搭棚过节，"那日以色列人大大喜乐"（尼8:13-18）。神也吩咐每逢七年在住棚节向全民宣读律法（申31:10-13）。撒迦利亚书看见将来列国的人都要上耶路撒冷"守住棚节"（亚14:16）。

### 在新约的应验

前两个节期在耶稣第一次来时已经清楚应验了。住棚节的应验有一部分已经发生，最终的完成还在前面。

约翰福音的序言说："道成了肉身，住在我们中间"（约1:14）。这里的"住"，希腊原文的意思就是"支帐棚"。旷野中神住在会幕里，如今神的儿子取了人的身体，在人中间支搭帐棚。

约翰福音第7-8章整段发生在住棚节。耶稣时代，这个节期有两个重要仪式：祭司每天从西罗亚池打水，浇在祭坛上，祈求秋雨；圣殿院子里点起巨大的灯台，照亮全城。正是在这个背景下，"节期的末日，就是最大之日，耶稣站着高声说：'人若渴了，可以到我这里来喝'"（约7:37）。随后他又说："我是世界的光"（约8:12）。这两个仪式的记载来自犹太传统文献，但和约翰福音的叙述吻合得很自然，大多数解经家都接受这个背景。

最终的应验在启示录。约翰看见新天新地，听见一个声音说："看哪，神的帐幕在人间，他要与人同住"（启21:3）。这里的"帐幕"和"同住"，用的是和约翰福音1:14同一个字根。那时我们不再住在临时的棚子里，也不再需要提醒自己神曾经同在，因为神将永远住在他的子民中间。启示录7章那手拿棕树枝、在宝座前欢呼的无数人（启7:9-10），也带着住棚节的色彩。

住棚节第八日的特别意义

住棚节第八日在后来的犹太传统中叫"第八日严肃会"（Shemini Atzeret），被看作一个独立的节日。犹太拉比有一个很温暖的解释：七天的节期结束，众人要散去了，神就像主人留客，说："你们的离去让我不舍，请再留一天。"这是后来的传统解释，不是经文明说的，但它抓住了"留住"这个字根的意思。

这也可以作为背景，帮助理解约翰福音7:37。约翰说耶稣在"节期的末日，就是最大之日"高声说："人若渴了，可以到我这里来喝。"解经家对这里指的是第七日还是第八日的严肃会有不同看法，但无论哪一天，都是节期最高潮、众人即将散去的时刻。

## 五、把三个节期连起来看

| 节期                   | 农事     | 记念                     | 应验                                   |
| ---------------------- | -------- | ------------------------ | -------------------------------------- |
| 逾越节、除酵节、初熟节 | 大麦初熟 | 羊羔的血救赎，出埃及     | 基督受死；基督复活作初熟的果子         |
| 七七节（五旬节）       | 小麦收完 | 收成的喜乐，与穷人分享   | 圣灵降临，福音第一次大收割             |
| 住棚节                 | 全年收藏 | 旷野中住棚，神住在会幕中 | 道成肉身住在人间；将来神的帐幕永在人间 |

这三个节期合起来，像一年的收成，也像救恩的全过程：从开始收割，到收割完成，再到全部收进仓里。

神设立这些节期，不是让以色列人去"做"什么来赚取祝福。每一个节期都是先记念神做了什么：他救赎了，他供应了，他同在了。人所做的只是来到他面前，领受、欢喜、感谢。这正是福音的样式。

圣经清楚说的已经足够丰富：羔羊已经被杀，初熟的果子已经复活，圣灵已经浇灌，神已经住在人间，而且将要永远住在人间。
