# 微信公众号合规审校清单

脚本（`replace_vocab.py`）只能机器检查其中一部分，标 🤖 的条目已写进 `audit-rules.json`；其余靠人工审校。
**维护方式**：每发现一个新的误伤词或新的残留类型，补到 3.2（`shen-protected.json` / `audit-rules.json` 的 `shen-false-positive`）或第九节（`audit-rules.json`），这份清单会越来越准。

## 总原则
1. 保留神学论点、论证结构和作者语气，只改触发风险的字句。能改一个词不改一句，能改一句不删一段。
2. 风险内容只做“删除”或“泛化”，绝不使用拆字、斜杠、缩写字母、谐音、拼音、插入符号等方式规避检测。
3. 按下方顺序逐节检查，风险从高到低。
4. 输出格式：
   - 修改后的全文
   - 修改清单（表格：原文 / 改后 / 原因 / 规范条款）
   - “需作者确认”清单：政治相关修改、可能改变原意的修改
   - 发布提醒：是否需勾选原创/AI辅助声明、是否需补授权说明

## 一、政治敏感（可能删文封号）🤖
触发：讽刺或影射现行体制的口号、标语、领导人；“集权”“极权”“专制”与“今天”“当下”对照；鼓励抗议、抵抗且有现实指向。
处理：删除现实对照和口号，保留历史与神学案例（马德堡认信、朋霍费尔等）。全部列入“需作者确认”，不得自动删除整段。
例：
- 原：“跟今天集权政府内部发生的那些事相比，当年的英国还算克制”
  改：“当年的英国，说实话，还算相当克制”
- 原：引用“英特纳雄耐尔”“为人民服务”作讽刺
  改：删除，以“以‘我要救你’之名登场的暴政”概括

## 二、规避检测写法（规范1.2，直接导致不推荐）🤖
触发：拼音缩写（JH、JD、SJ等）、斜杠或空格拆字（集/权）、谐音字、插入符号。
处理：还原为正常中文，或整体改写该句。
例：
- 原：“藐视恩典，乃是JH之死”“JH（会众）”
  改：“藐视恩典，乃是会众之死”

## 三、替换体例
作者有固定替换习惯：“神”→至高者，“耶稣”→伊诶溯斯，“基督”→受膏者，“福音”→好消息，“圣经”→圣典，“牧师”→小牧人，“教会”→会众。（完整对照见 `vocab.json`。）

**3.1 一致性** 🤖：同一篇内统一。发现未替换的（如“耶和华”“十字架”“神学院”）或多种写法并存（“圣学”“关于至高者的学说”“圣学院”），列出并询问作者统一为哪种，不自行决定。

**3.2 误伤还原（每篇必查）** 🤖：
- 大至高者 → 大神
- 如来至高者掌 → 如来神掌；火云邪至高者 → 火云邪神
- 至高者迹 → 神迹
- 至高者圣的（原“神圣的”）→ 圣洁的
- 同时检查：精神、神经、神秘、眼神、神话、神奇、女神、财神、封神、神仙、出神、神色、神态、神韵、留神

**3.3 不得替换**：书名、论文名、出版物、他人直接引语、文献出处。
例：《沃沃托萨关于至高者的学说》→《沃沃托萨神学》

**3.4 禁用“苦刑柱”**（耶和华见证人术语）🤖，改“十字架”或“受难”。
（已定：“十字架”也可能敏感，`vocab.json` 里统一换成“受难架”，复合词“钉十字架”→“处以受难之刑”、“十字架神学”→“受难的学说”、“十字架的道”→“受难的道”。不用“苦刑柱”“刑架”：前者禁用，后者有刑具渲染的观感风险。如要改写法，只改 `vocab.json`。）

**3.5 提醒作者**：替换写法本身可能被视为规避，影响推荐。只提醒一次，不改作者的体例。

## 四、医疗与伪科学（规范5.1、5.2）🤖
触发：中医、偏方、穴位、具体病名、“治好”“根治”、创造论、恐龙、化石、地球年龄、进化论争议。
处理：病名和疗法泛化，科学争议细节删除，保留属灵论点。
例：
- 原：“我这个癌症能治好”“有个穴位按一按眼睛就能睁大”
  改：“我的病跟别人不一样”“有个方法试一试也许会好一点”
- 原：“讲座的核心是创造论……至高者造没造恐龙，石油是怎么来的”
  改：“讲座的主题是科学与信仰……问题一个比一个尖锐”
- 原：“祷告治好了他的病”
  改：“他在病中经历了至高者的同在”

## 五、低俗擦边与暴力（规范4.4、4.5）🤖
触发：色情场所、招揽话语、性暴力情节、血腥细节。
处理：一句概括代替具体描写。
例：
- 原：“洗头房……‘帅哥，来玩儿呀’”
  改：“那几条街上开着一排半掩着门的小店”
- 原：“求表扬不得，就把她强奸了”
  改：“求表扬不得，最后犯下了大错”

## 六、惊悚与观感不适（规范5.3.1、5.3.2）🤖（仅查标题）
触发：标题含“地狱”“死亡”“恐怖”；大段描写地狱刑罚、尸体、灾难死亡、审判致死。
处理：标题改用文章主线意象；保留经文引用，削减渲染性描写。
例：“地狱的日常” → “我们都坐在橱窗里”

## 七、翻译稿（规范2、7.2，防判搬运）
凡翻译他人讲道、论文、书籍：
- 开头须有作者自写导读：原作者简介、写作背景、为何今天值得读
- 关键术语加译者注（如客观称义、恩典之道）
- 文末注明：原题、原作者、原载出处、所依据的译本及译者、授权情况
- 无导读时，生成导读草稿供作者修改，标注“待作者审定”
- 提醒作者：不要以“转载”形式发布

## 八、标题（规范5.3.3、5.3.4）
- 不用悬念式、话说一半的标题
- 标题与主旨一致；可加副标题点明主题
- 删除正文开头重复的标题

## 九、发布前通查
- 文末无网页残留（如“……- 每日头条”“××库存图片. 图片包括有……”）🤖
- 图库图片提醒确认授权
- 无个人微信、群二维码、外部链接 🤖
- 无重复词句、错字、多余语气词、中英混杂（如“reluctant”）🤖
- 经文缩写准确：约壹/约贰/约叁（非“约一”）、彼前/彼后、帖前/帖后、提前/提后；全文体例统一 🤖
- 引用的书籍、史实出处准确；未读原著注明“据转述”；无法核实的页码、年份列入“需作者确认”
- 事实细节核对（如人物、地点、经文场景）
- AI 参与较多时，提醒勾选 AI 辅助创作声明
