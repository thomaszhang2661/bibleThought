# 丢特腓——恶言暴君

• 对于丢特腓这样的人，不要被他勾引，不要被他拖下水，不要耍他的把戏，不要堕落到他的层次。“行恶的人未曾见过上帝”。丢特腓不具备上帝的力量，不遵从上帝的旨意，

他最终败亡堕落。我们需要的是上帝的认可，而非其它任何事，上帝定然不会认可丢特腓的所作所为。

• 与暴政和恶言争战的最佳方式就是效法善，在真理中寻求庇护而非恶言相向。以德报怨，

以爱消恨。约翰说：“行善的人属乎上帝”。相信上帝会祝福遵行他旨意并按照他的方式指导事工的人。上帝的圣道、旨意和力量必将得胜。

• 低米丢与你同在。该犹认识低米丢，我们不认识，他应该是该犹的会众中的一位积极的和富有建设性的同工，一起抵抗丢特腓的邪恶行为。或者，他是众位“弟兄”中的一员，

是由约翰派出的通讯员和信使，传递这封书信。人们会推测，约翰三书中的低米丢或许是使徒行传 19:24 中那个同名的人，那个制造亚底米银龛的银匠，是他煽动了以弗所的暴乱。

会不会是他归信了基督，现在成为约翰从以弗所派出的信使之一？
