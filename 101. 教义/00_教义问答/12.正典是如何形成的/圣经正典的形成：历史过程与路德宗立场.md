# 圣经正典的形成：历史过程与路德宗立场

## 引言

"圣经正典是怎样确定的？"这是许多基督徒都会问的问题。是教会权威人士坐在一起投票决定的吗？还是神在某个时刻突然宣布的？事实上，圣经正典的形成是一个更复杂、更有机的过程。本文基于Pieper《基督教教义学》、Lange《神爱世人》以及WLS诸多论文，简明介绍正典形成的历史过程及路德宗的独特立场。

---

## 一、什么是正典？

**正典（Canon）** 的字面意思是"测量用的杆"，在宗教背景下，它指的是教会认可为圣灵所默示、具有权威性的圣经书卷的完整清单。

关键点：

- **圣经本身及路德宗信条都没有列出一份明确的"正典书卷清单"**
- 正典的确定既涉及信仰问题（这些书是否真的被圣灵默示？），也涉及历史问题（教会如何确认这些书的使徒性和真实性？）
- 路德宗不认为圣经正典是教会"创造"出来的，而是教会"承认"和"领受"的

---

## 二、圣经正典如何形成？

### **第1阶段：使徒时代的权柄确立（1世纪）**

最初的基础是**使徒的权柄**：

- 耶稣对门徒说："听你们的，就是听我；弃绝你们的，就是弃绝我"（路10:16）
- 保罗教导教会要接纳他的书信为具有基督权柄的教导（帖后2:15；3:14）

结果：

- 初代教会认识到使徒所写的书卷、所传的道具有耶稣基督本身的权柄
- 各教会开始抄录使徒的书信，并在教会间流传

### **第2阶段：自然汇聚与广泛认可（2-3世纪）**

到2世纪初，一个核心的书卷集合逐渐形成：

- **四福音书合集**（马太、马可、路加、约翰）
- **保罗的十四卷书信**（包括希伯来书，尽管作者身份有争议）
- **其他使徒书卷**（彼得前后书、约翰一二三书、雅各书、犹大书等）
- **启示录**（虽然部分教会对其有保留）

**重要特点：这不是某个权威机构"宣布"的，而是教会之间"安静的历史过程"**

## 三、两类书卷的区分

### **第一类：Homologoumena（普世公认书卷）**

这些书从初代教会开始就被**全体一致**公认：

- **四福音书**
- **保罗明确确认的书信**（罗、林前、林后、加、腓、帖前、帖后）
- **使徒行传**
- **约翰一书**
- **彼得前书**

**特征**：从未有任何主流教会质疑过它们的使徒性或权威性

### **第二类：Antilegomena（争议书卷）**

这些书卷在初代教会中存在**部分人的怀疑**，主要是关于**作者身份**：

| 书卷           | 争议点                                 |
| -------------- | -------------------------------------- |
| **希伯来书**   | 作者身份不明（保罗？亚波罗？巴拿巴？） |
| **雅各书**     | 是否为主的兄弟雅各所写                 |
| **犹大书**     | 作者身份相对陌生                       |
| **启示录**     | 是否为使徒约翰所写                     |
| **彼得后书**   | 作者身份引发较多讨论                   |
| **约翰二三书** | 使徒性有争议                           |

**重要澄清**：对这些书的质疑，**不是说它们不是圣灵默示的**，而是初代教会对**谁写的、是否直接来自使徒**这些历史问题有不同的看法。

---

## 四、路德宗对这一区分的态度

### **1. 马丁·路德的立场**

路德遵循初代教会的判断，在他的圣经序言中保留了这一区分：

- 他认可这些书的真实性和价值
- 但在关键教义问题上，会优先参考普世公认书卷（homologoumena）而非争议书卷（antilegomena）
- 他说这些书卷在"古代有不同的评价"（appealing to Eusebius，_Church History_ III, 25）

### **2. 之后的路德宗传统**

开姆尼茨（Chemnitz）：

- 强烈反对罗马天主教会在特伦托会议（1546）上的做法
- 特伦托会议简单地用权威宣布"这些就是正典"，还咒诅不接纳者
- 开姆尼茨指出，这违反了圣经本身的权威性

密苏里公会（Missouri Synod）的神学家，如瓦尔特（Walther）：

- 明确指出：若一位神学家真诚接纳所有homologoumena为正典
- 但对某几卷antilegomena的正典性存有疑问
- **这绝不能将其定为异端或危险的假教师**
- 因为路德宗教父本身就持这样的态度，他们这样做不是对圣言的轻慢，而是良知的表现

### **3. 关键原则**

路德宗的立场总结为：

✓ **承认**这两类书的神学区分  
✓ **拒绝**教会权威强行关闭讨论的做法  
✓ **坚守**antilegomena中所有教导都与homologoumena的核心教义完全一致  
✓ **保留**对争议书卷具体问题的学术讨论空间  
✓ **维护**圣灵内在见证的中心地位（不是教会权威）

## 五、为什么路德宗保留这个区分？

### **1. 历史诚实**

否认这个区分就是否认初代教会的历史事实。优西比乌清楚地记录了这一点，没有什么权力能改变历史。

### **2. 护教价值**

很多人攻击正典的完整性时，会列举这些历史争议。如果我们：

- **坦诚**这些争议存在
- **解释**为什么这些书仍然是圣灵默示的
- **说明**为什么路德宗仍然使用它们

...这比试图掩盖这些争议要有说服力得多。掩盖只会让人日后发现真相时更加失望。

### **3. 神学力量**

这表明：

- 我们的信仰**建立在对圣灵见证的信靠上**，而不是对教会权威的盲从上
- 我们**敢于承认不确定的地方**，这恰恰显示出对神的话语的尊重
- 我们**不需要人为的一致性幻象**来维护圣经的权威

---

## 六、现代基督徒需要知道什么？

### **对日常信仰的影响：几乎没有**

重要的是：

- **antilegomena中没有任何教导违背homologoumena的核心真理**
- 关于救恩、基督、圣灵、成圣等根本教义，所有66卷书的教导都完全一致
- 关于这些争议书卷的正典地位的讨论，**是学术与历史问题，不是信仰问题**

### **釜底抽薪原则**

如果你不确定某卷书的地位，有个简单的原则：

> 绝不能用antilegomena的表述限制或否定homologoumena的清晰教导

例如，即使对雅各书的正典性有疑问，也不能因为它说"信心没有行为是死的"（雅2:26）就否定或限制保罗清晰的"因信称义"教导。恰恰相反，要用保罗的教导来正确理解雅各书。

### **路德宗的智慧**

路德宗对正典的态度体现了一种成熟的信仰：

- 不盲从教会权威 ✓
- 不否认历史事实 ✓
- 坚持圣灵见证的终极权柄 ✓
- 在不确定处保持谦卑 ✓
- 在确定的真理上坚定不移 ✓

## 八、小结

圣经正典的形成是：

1. **历史过程**——初代教会逐步认可使徒性的书卷
2. **自然汇聚**——不是某个权威一次性决定，而是教会在圣灵引导下的认可
3. \*\*有等级的——homologoumena更核心，antilegomena仍然是圣灵默示但在历史上有过争议
4. **靠圣灵见证**——不靠教会权威的强行宣布，而靠圣灵在信徒心中的见证

作为路德宗基督徒，我们：

- **坦诚承认**这个历史事实
- **充分信靠**圣灵的见证
- **坚守真理**的核心教导
- **谦卑对待**学术上的悬而未决的问题

这就是成熟信仰的表现。
