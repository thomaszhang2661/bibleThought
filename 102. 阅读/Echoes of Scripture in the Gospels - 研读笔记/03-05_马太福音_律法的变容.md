# 第二章 马太福音 §10 律法的变容——马太的经文解释学

## 三、第10节 妥拉的变形：马太的释经方法论

Hays 指出，马太富有想象力地运用圣经，来重述以色列的故事、叙述耶稣的故事、并勾画教会与异教世界的关系。基于以上全部发现，关于马太释经的典型模式与策略，可以得出怎样的结论？在处理具体的主题性着重点之前，他先提出三点关于马太处理圣经文本之形式与方法的总体观察。

### 1. 三点方法论总观察

**其一**，与初看给人的印象相反，把马太的方法简单定性为「证据文本式」(prooftexting)解经，或认为它执迷于「预言/应验」模式，都是不准确的。诚然，马太确实相信，先知的话语已经在耶稣的生平中、借着耶稣的生平得以成就，他也的确用心地把聚光灯打在他所辨认出的、耶稣生平与更早先那些神秘先知神谕之间具有天意色彩的对应之处。然而，Hays 强调，这些预言与应验的实例，只是一幅更大地图上若干个亮点，只是一个远比表面所见庞大得多的互文实在中的片段。对马太而言，以色列的圣经构成了他笔下人物与他的读者共同栖居、共同活动其中的那个象征世界。神与以色列打交道的故事，是一整套综合性的母体，马太的福音叙事正是从这套母体中生发出来的。因此，那些应验引文，邀请读者进入一场持续的探索之旅，去探究律法和先知全体，究竟如何在耶稣与天国里得着成全（太5:17）。

**其二**，Hays 重申此前已观察到的现象：马太的圣经引文有时会把两处或更多旧约文本交织在一起，把一处经文的措辞嵌入另一处经文之中。他的分析所得出的结论是：这既不是出于记忆的偶然误引，也不是单纯依赖某个与马所拉文本、七十士译本都不同、却又不为人知的文本传统，而是这些混合式的引文，似乎是一种暗引式的、具诠释建构性的写作手法：它们邀请读者同时回忆起两处不同的圣经语境，思考二者如何彼此照亮，或辨识出这两处潜文本如何共同促成对福音书所叙述之事件的精细诠释。例如，当马太关于弥赛亚将诞生在伯利恒的引文（太2:6）暗中把撒母耳记下5:2的措辞与弥迦书5章的措辞编织在一起时，听出这一回响的读者，便被引导在大卫继承王位、取代扫罗这一叙事背景下，去理解幼年耶稣对希律王权的挑战。

Hays 列出本章中还讨论过的其他若干类似例子（以表格形式呈现）：

| 马太段落 | 交织的圣经互文 |
|---|---|
| 太2:6 | 弥迦书5:1-3 + 撒母耳记下5:2 |
| 太4:14-16 | 以赛亚书9:1-2 + 以赛亚书42:6-7 |
| 太11:29 | 便西拉智训51:27 + 耶利米书6:16 |
| 太21:5 | 以赛亚书62:11 + 撒迦利亚书9:9 |
| 太27:39 | 诗篇22:7 + 耶利米哀歌2:15 |

Hays 指出，这一手法在马太笔下有的例子明显，有的则相当隐晦，其中许多恐怕需要「为天国受教作门徒的文士」（太13:52）那样的读者能力才能辨识出来。马太并没有把他叙事中互文交织所蕴藏的全部珍宝，都摆在明处任人一览无余。

**其三**——这里 Hays 只是重申一项学界共识——马太对先知性文本、尤其是以赛亚书，怀有特殊的亲近感。以赛亚书在马太「操作性的正典」中占据特殊位置：它提供了认出耶稣为以马内利、并理解教会向万民传扬福音之使命的钥匙。但与此同时，Hays 提醒不应忽视其他文本在马太故事中所扮演的关键释经角色，例如申命记6:5（「你要……爱耶和华你的神」）、何西阿书6:6（「我喜爱怜恤，不喜爱祭祀」），以及义人受苦的诗篇。同样，仔细阅读马太福音，也会发现以色列智慧文学那略显隐没却无所不在的影响。马太的引文和暗引横跨整部圣经正典，而且——部分因为经文交织这一现象——鼓励读者把以色列的圣经视为一大片庞大、复杂却又浑然一体的见证人云彩，预表着在马太福音中以崭新的清晰度得到表达的那一实在。

### 2. 从「重组」到「变形」：马太释经想象力的性质

Hays 追问：那么，我们该如何刻画这一「实在」？他提到 Rowan Williams 曾提出，耶稣的死而复活引发了一场旷日持久的「宗教语言重组」(reorganization of religious language)过程，新约诸文献正是这一过程最早的见证。Hays 认为，若真要形容马太与以色列圣经之间的这种互动关系，「重组」这个词未免过于温和保守了。他提出，更准确的说法或许是「变形」(transfiguration)，着重强调马太诠释异象中的预表性(figural)维度。

### 3. 四个总结性主题

Hays 提出，可以把马太赋予以色列圣经的这种「形态」，归纳为以下四个方面：

**(a) 圣经作为以色列的故事**：马太首先并不是把以色列的圣经当作一部规条诫命的汇编，也不是当作一部关于弥赛亚的孤立预言选集，而是当作一个故事，勾勒出神与以色列打交道的宏大轨迹。这个故事的情节可以概括为如下的叙事序列：拣选、王权、悖逆、流亡、弥赛亚式的拯救。这正是开篇的家谱以及降生婴幼期叙事中那些具有隐喻性、预表性质的圣经引文所勾勒的情节。这一叙事序列——以流亡与归回的模式居于中心——为我们此后如何诠释马太耶稣故事中的一切内容，确立了参照框架。即便马太偏好把先知文本当作预言性神谕来读，这种偏好本身的神学可理解性，也源自他的一个信念：全部圣经乃是一个宏大而连贯的故事，其中以色列过去历史的种种要素，都指向一个弥赛亚式的终局，在这终局中，神终将与他的百姓同在（参太1:21-23；28:20）。这一终局使此前的整个故事发生了变形；这个经过释经性变形的以色列故事，对马太而言依然是一个构成性的互文，是一部「根基故事」(Grundgeschichte)，是耶稣故事的首要母体。

**(b) 圣经作为呼召人心转变、彻底顺服与怜悯的号召**：马太的读者被召入一个严格的、要求苛刻的门徒群体，活在耶稣对律法之激进诠释之下。他们被期望成为「立在山上的城」，在共同生活中彰显彻底顺服的意义。在这一点上，Hays 指出，马太事实上与他大量论战所针对的法利赛式犹太教非常接近。使马太的方案有别于同时代其他犹太人方案的，不仅在于耶稣教导中所确立的具体哈拉卡规范（例如关于离婚、起誓、报复伦理的教导），更根本地在于他对内在动机之转化这一点的独特强调。妥拉被重新配置为对心灵转变的呼召。唯有如此，耶稣门徒的义才能超过文士和法利赛人的义。然而，Hays 指出，马太赋予这种彻底顺服的呼召一个独特的转折：他把怜悯当作诠释整部律法的钥匙。马太一方面坚持律法的具体诫命依然有效（太5:17-20；23:1-3；23:23），另一方面又把怜悯与饶恕突显为律法信息的核心。在马太的思想中，这两个要素之间存在着不可避免的张力——这并非矛盾，而是着重点与情感取向上的对照。归根结底，如果对彻底顺服的呼召，有时似乎与对罪人施行饶恕的呼召相冲突，这一张力该如何化解？马太并未提供一套系统性的解决方案，但他释经策略的总体倾向，是把怜悯（或如22:34-40中的爱）当作最深层的实在，为诠释具体诫命提供批判性的框架。在此，我们再次看到，与马太同时代其他犹太人对妥拉的构想相比，马太对妥拉作出了重大的重新配置。

**(c) 圣经作为对基督的预表**：Hays 认为，这一点或许最需要对大众关于马太福音的普遍印象作出实质性的纠正。马太的基督论释经，绝不能被理解为随意挑拣几处生动诱人的先知证据文本。相反，这部福音书创造出一系列微妙且不断变化的预表模式，邀请读者辨识出耶稣与许多不同旧约先驱人物之间的叙事对应关系：以撒、摩西、大卫、耶利米、智慧、仆人、义人受苦者、人子，等等。而在这万花筒般纷繁多样的预表类型之下，最根本的预表，乃是马太惊人地把耶稣认定为以马内利、神与我们同在。以色列圣经中如此纷繁多样的故事，怎么可能全都以某种方式指向耶稣这唯一一个人物？马太福音复杂预表设计所隐含的答案是：这些圣经故事，无一例外，都是以某种方式被设计出来，用以揭示关于神之身份的某些方面。当耶稣/以马内利登上叙事舞台时，我们便能够认出，他比故事前面各章出现的所有先驱人物都「更大」，与此同时，他又把蕴藏在这些先驱人物故事中的种种意涵都聚集在自己身上。他之所以能够做到这一点，是因为他同时是以色列命运的弥赛亚式承担者——「一切的义」终于在他身上得以成全——又是以色列之神的具体化身，那位拥有一切权柄、要一直与百姓同在直到世界末了的那一位。Hays 特别强调，马太福音并没有任何证据显示，其作者曾试图用本体论式或命题式的语言，去阐述这一悖论性实在——迦克墩会议还远在未来，它的概念范畴也在马太的视野之外。尽管如此，编织在马太故事中的这些叙事性预表类型，却帮助制造出了后来迦克墩会议及其后继者们试图解决的神学难题：耶稣怎么可能既是以色列，又是以色列之神的具体化身？马太并未给出解释，但他以叙事的方式肯定：这两种描述，对他福音书中的这位中心人物而言，都是真实的。

**(d) 圣经作为向万民宣教的号召**：马太描绘出一幅耶稣跟随者群体的图景——他们既充满爱，又彻底顺服于耶稣所变形了的妥拉。这样一个群体存在于世的关键目的之一，就是把外邦人带向光明，使他们也能成为门徒。在马太叙事的整体设计中，登山宝训里耶稣的劝勉——「你们的光也当这样照在人前，叫他们看见你们的好行为，便将荣耀归给你们在天上的父」（太5:16）——预表了福音书结尾的「大使命」（28:18-20）。那些将要看见这光的局外人，理当包括先前「坐在黑暗中」的外邦人（4:16）。门徒彰显这光的使命，无非是神在以赛亚预言中赋予以色列之使命的延伸与成全：「我要使你作外邦人的光，叫你施行我的救恩，直到地极」（赛49:6）。此外，正如已经看到的，门徒借着执行这一使命，也将促成但以理异象中人子的权柄(ἐξουσία)临及万国这一异象的应验。因此，马太把以色列的圣经重新配置为一份宣教宣言，为圣经的叙事性解读提供了最后一个、也是末世论性质的元素。借着使万民作门徒，耶稣的跟随者把万民带入以色列故事的最后一章——在这一章里，神的百姓被那位复活的人子的同在所扶持、引导，直到世界的末了。

### 4. 全章结语

Hays 在全章结尾处指出：以上四个要素，可以说都是第一世纪犹太思想与实践的有机发展。马太所设想的，是以色列得蒙救赎、从流亡中归回，在一位弥赛亚式拯救者的带领下过彻底顺服神的生活，而这位拯救者将仁慈地统治万国。他指出，在第二圣殿晚期及其后不久的其他犹太文献中，不难找到与这一构想类似的东西：所罗门诗篇、昆兰古卷、以诺一书都会立刻浮现脑海。马太清晰地契合于这一犹太末世论期望的整体图景之中。然而，Hays 强调，马太的叙事同时也构成了对这些期望的惊人转化，因为马太所执行的这场对妥拉的诠释学「变形」，在每一个环节都依赖于他对唯一一人——耶稣，以马内利——独一权柄的叙事性呈现。在耶稣复活的光照之下，以色列、妥拉、弥赛亚与万国，全都获得了崭新的形态。既然天上地下一切的权柄，已经交给了马太所讲述的这个故事中的耶稣，那么一切事物都必须被重新理解。
