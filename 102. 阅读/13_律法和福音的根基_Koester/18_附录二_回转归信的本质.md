# 附录二 回转归信的本质

作者以表格形式对比了路德宗与改革宗对"回转归信"（conversion）这一经历的不同理解。

| | 路德宗 | 改革宗 |
|---|---|---|
| **是什么促成了回转归信？** | 圣灵借着律法使人认识到自己是罪人，使人经历到对上帝的惧怕、以及对自己永生归宿的不确定。 | 一个人被引导，产生了想要活出更美好生命的渴望——这渴望的具体缘由因人而异：或是想与上帝和好，或是想摆脱罪在自己生命中造成的恶果，或是想消除罪给社会带来的危害。律法的宣讲总带有同一个特征：指出罪所带来的困境，以及基督信仰将要给予的解脱。 |
| **人们被告知去做什么？** | 人被告知，只需相信基督已在十字架上为自己的罪而死，从而安息在上帝恩慈的赦免之中；并被提醒，靠自己"做"任何事，只会妨碍上帝的赦免临到自己。 | 人被告知，要让自己顺服于圣灵的引导；如果向圣灵敞开自己，圣灵就会住在他们里面，并赐下活出敬虔生活的能力，以及对一切罪的赦免。促成回转归信的，通常是一段"律法"信息，而非"福音"信息。 |
| **它带来了什么？** | 带来与上帝之间的和好，带来渴望活出讨上帝喜悦之生活的心志，以及对被赐予服事上帝之能力的感恩——这些是这种回转归信经历的核心。 | 使人重新燃起服事上帝的渴望，并带来一种意识：因为在基督里、在上帝眼中已经成为圣洁，所以理当活出圣洁的生活。 |
| **与回转归信相关联的感觉** | 一个人如何感受自己所领受的赦免，完全因人的性格而异；但这种感受总是以对圣道与圣礼——上帝借以赐下赦免的客观途径——的珍视为特征。 | 通常由各宗派仔细界定，从平静的领受到极力强调主观的情感体验不等；常以一种界限分明的"我找到了"式经历为标志。 |
