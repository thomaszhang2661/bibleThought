# 创世记 2:4–25 校对备忘

1. 位置：“我们若是仔细研读第 6 节的希伯来文本，就会发现和合本的译文错得确实有些离谱”／问题：英文为 raises serious doubts about the correctness of the AV rendering，语气是“令人对其准确性产生严重怀疑”，“错得离谱”比原文重得多。另，英文说的是 AV（钦定本），中文换成了和合本，属译者改写但未加译者注。／建议：“……就会对和合本（及钦定本）这一译法的准确性产生严重怀疑”，并加注说明替换。
2. 位置：“古代的编辑果真这般眼瞎又愚蠢吗”／问题：英文为 so blind and clumsy，原文语气是学术论辩，“眼瞎又愚蠢”过于口语和刻薄。／建议：“竟会如此盲目又笨拙吗”。
3. 位置：“因此，这第三种用法不可用指某个时代”／问题：英文为 Thus it does not designate an era，是陈述事实（并不指某个时代），“不可”读来像禁止。／建议：“因此，这第三种用法并不指某个时代。”
4. 位置：“在 Ain Waw 系列动词（即双字母动词）中”／问题：英文只写 the Ain Waw verbs，指“中间字母为 waw 的动词”（中间弱动词）；“双字母动词”是译者自加，且不对应原文，容易误导。／建议：“中间字母为 waw 的动词（Ain Waw 动词）”。
5. 位置：“在那里又有琥珀和玛瑙石”及后文“琥珀是一种从樟类植物中提取的芳香树脂”／问题：英文为 bdellium（一种香树脂），不是琥珀（amber，化石树脂）；和合本此处为“珍珠”，中文这样译会与后文“芳香树脂、用于制香”的说明冲突。／建议：“……有 bdellium（一种香树脂）和红玛瑙”，或在首次出现处加注。
6. 位置：“帖 1:1”（谈古实的引证经文，“列下 19:9；帖 1:1；结 29:10”）／问题：英文为 Est 1:1，指以斯帖记；“帖”在中文圣经缩写里通常指帖撒罗尼迦前后书。／建议：改为“斯 1:1”。
7. 位置：“的希伯来文本自基特尔第三版（由保罗·卡赫尔筹划）以来……”／问题：句首缺主语。英文为 Biblia Hebraica 的希伯来文本（Biblia Hebraica 的标题在提取时丢失，混入了页码行），不影响理解但读不通。／建议：补为“《希伯来圣经》（Biblia Hebraica）的希伯来文本自基特尔第三版……”。
8. 位置：“耶和华典作者……祭司典作者”（2:4 脚注一）与前言“祭司法典”／问题：见前言备忘第8条，术语不统一（Priestly writer 与 Priestly Code 混译）。／建议：全书统一。

本备忘只抽查了部分，不是全文校对。
