# 创1-2 简要笔记

> 标记说明：没有标记的是原笔记（有错的地方已直接改在原文里）；【补充】是新加的内容；【待定】是还没想清楚的问题。

# 创1:1-2？

怎么理解创1:1-2，是一个总括说明，或者1:1是第一个创造的动作？

【补充】两种读法：

|      | 读法A：1:1 是总括                                   | 读法B：1:1 是第一个行动                                                               |
| ---- | --------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 意思 | 1:1 像标题或摘要，概括整个六日                      | 1:1 是“起初”造天地这个动作本身                                                        |
| 1:2  | 从这里开始讲细节                                    | 描述这个动作之后，地当时的样子                                                        |
| 支持 | 1:1 在语法上确实可以当独立句读（双方都承认）        | 1:2 开头的 waw 把两节连起来，1:2 的三个小句都是描述状态；1:3 的“神说”才是叙事往前推进 |
| 困难 | 难以解释 1:2 开头的 waw（它让 1:1 和 1:2 连在一起） | 需要说明“起初”和“第一日”的关系                                                        |

Lawrenz/Jeske 注释（本仓库 `1. 创世记/00_创世记注释_Lawrenz_Jeske`）取读法B：1:1 是独立句，既不是单纯的标题，也不是对整章的总述；1:2 开头的 waw 排除了这两种读法。

【补充】相关的两个旁证：

- 出20:11 说“六日之内造天地海和其中的万物”，注释把“起初”这个阶段算在第一日之内，但第一日的本质仍由 1:5 定义（有光，有暗）。
- 间隔论（在 1:1 和 1:2 之间插进极长的时间）与出20:11、创1:31 都有冲突，保守的路德宗一般不采用。

【待定】我不确定是总括还是开场。建议先这样记：**暂倾向读法B（开场），因为 waw 的语法证据最硬；读法A 保留，等再读几家注释后再定。**

# 1:2 运行

hover这个词是老鹰盘旋的动作，好像一只鸟在护理幼鸟所在的巢穴。

【补充】

- 希伯来文是 rachaph。申32:11 用同一个动词形容鹰在雏鹰上面“搧动”，这是最好的对照经文。
- 小心不要写成“孵化”：注释说这个动词的 Piel 词干没有“孵化、孕育”的意思，意思是“翱翔、盘旋”。“护理”比“孵化”更接近。
- “神的灵”：这里就是圣灵，创造一开始，三位一体的上帝已经在场（可以和 1:1 的“神”、1:3 的“神说”一起读）。

# 创造的节奏

1 神说
2 就有/成了
3 神看着好
4 有晚上，有早晨，是几日。

这个节奏说明：1 上帝的大能 2 完美的世界 3 上帝是“好”的源头。

【补充】节奏里的几个有趣的变化：

- 第二日没有“神看着是好的”（马所拉文本）；第三日有两次（1:10、1:12）；第六日是“甚好”（1:31）。
- 1:5 的“第一日”用基数（“一日”），后面是序数（第二日、第三日……），常被注意到。
- 第七日没有“有晚上，有早晨”。希伯来书 4:3-11 把它读成仍在持续的安息。

# 穹苍（和合本译作“空气”）

和合本创1:6-7 把希伯来文 raqia' 译成“空气”，1:8 神称它为“天”。“空气”是一个很现代的译法，raqia' 的意思是**穹苍**（被展开的空间），不是“空”。

【补充】

- raqia' 的词根是“捶打、展开”，例如出39:3 把金子“锤成薄片”。七十士译本译成 στερέωμα（坚固的穹苍），武加大译本译成 firmamentum，都带“坚固”的意思。
- 诗19:1 的“穹苍”也是 raqia'。
- 注释对第二日“天空之上的水”的看法（供参考）：它不遮掩日月星辰，最好视为某种巨大的、不可见的、透明的水蒸气罩一类的存在。这是注释的看法，不是定论。

# 成熟的果树

上帝创造的是一个成熟的果树。这棵树有两个年龄，一个是看起来的年龄，一个是被造的年龄。

【补充】

- 经文：1:11-12（第三日，造出的是“结果子的树”）、2:7（亚当）、2:22（夏娃）。亚当和夏娃一被造就是成年人。
- 可以连到教义问答19篇《上亿年的化石，和创世记真的矛盾吗？》，那一篇已经展开，包括戈斯的《肚脐》。

# 光体

光体是为了定自然节气。自然节气在大洪水中被摧毁，后上帝立约重建，永不再毁。

【补充】

- 经文：1:14-18（光体“作记号，定节令、日子、年岁”）、8:22（地还存留的时候，寒暑、冬夏、昼夜永不停息）、9:11-17（彩虹之约）。
- 1:14 的“节令”（mo'adim）和利未记23章的“节期”是同一个词，说明光体不只管时间，也标志着敬拜的时间。

# 1:24 牲畜

怎么看，动物被驯化这回事？创造的时候就是家畜吗？
圣经使用自然语言写成的。

创世的故事在这个场景被使用：晚餐后，几家人坐在篝火旁，一位爸爸给孩子们讲世界是怎么来的。

创世的故事不是在这个场景被使用：一群科学家在开学术会议，一位科学家在朗读他的世界起源理论。

【补充】

- 1:24 分三类：牲畜（behemah）、昆虫（remes）、野兽。这是按“人看到的、人怎么用”来分，不是现代的生物分类。
- “牲畜”（behemah）不等于“已被驯化”：同一个词也用于野生的兽，如申32:24、诗50:10（“千山上的牲畜”）。所以 1:24 只是在按“大型的、可使用的兽”分类，不是说创造时就是家畜。
- “自然语言”可以给它一个名字：**现象语言**（用人看到的样子来说，如“日出日落”，而不是“至高者绝对语言”，“自转公转”）。
- 篝火的场景可以加经文：诗78:3-6，父辈把耶和华的作为讲给子孙听。

# 1:26 形象

1 创世记内的证据，1:26 是“好”的源头的神的形象，给了人。5:3 在死亡的家谱里，堕落后，“死”在罪中的亚当生了孩子，形象与自己相似（死/罪的形象）

2 新约证据：歌罗西书和以弗所书（见下）。

【补充】新约证据：

- **西3:10**：穿上新人，这新人在知识上渐渐更新，正如造他之主的形象。
- **弗4:24**：穿上新人，这新人是照着神的形象造的，有真理的仁义和圣洁。
- 其他：西1:15（基督是不能看见之神的像）、林后4:4、罗8:29、林前15:49。

耶稣被问到该不该给凯撒纳税（太22:15-22；可12:13-17；路20:20-26）。他拿过一个银币，问：“这像和这号是谁的？”他们说：“凯撒的。”耶稣说：“凯撒的物当归给凯撒，神的物当归给神。”

银币上有凯撒的像，所以属于凯撒；人身上有神的像，所以属于神。这里暗示：人该把自己整个归给神，包括人的心。

【补充】
- “像”在希腊文里是 eikon，和创1:26-27 希腊文译本里的“形象”是同一个词，这是这个读法的依据。
- 这个联系经文本身没有明说，只能说是“暗示”，不宜写成明确的教导。
- **这是一个两头堵的陷阱**：经文直接说是要“陷害他”（太22:15；可12:13；路20:20）。
  - 答“该纳税”：会失去百姓的支持，因为犹太人痛恨罗马税，它提醒他们是被占领的民族。
  - 答“不该纳税”：会被告成反叛罗马，交给巡抚治罪。后来审判他时，罪名里果然有“禁止纳税给凯撒”（路23:2）。
- **为什么派这两批人**：法利赛人在宗教上反对向罗马纳税，希律党人支持希律家和罗马的统治。两批人一起去，不管耶稣站哪一边，总有一方可以去举报或煽动。
- **耶稣的回答破了这个局**：
  - 他没有直接答“该”或“不该”，而是让他们拿出银币。能从口袋里掏出带凯撒像的银币，说明他们自己已经在用罗马的钱了。
  - 他把话题从“税该不该交”转到了“你们属于谁”。他们“听见就希奇，离开他走了”（太22:22）。
- 【待核】银币上的铭文称皇帝是“神之子”，这是常见的说法，我没有在仓库里找到出处，引用前建议核对。

【补充】堕落之后还有没有神的形象？（已对照 Pieper《基督教教义学》卷一·人论 §2、§3）

- **狭义形象**：理智和意志有正确的倾向，真认识上帝，意志只愿遵行上帝（西3:10、弗4:24）。路德宗一致认为，堕落后完全丧失，在信徒里由基督重新恢复。
- **创9:6、雅3:9 怎么读，路德宗内部有两种：**
  1. 路德、菲利皮等：这两节说的是曾经有、将在基督里恢复的形象，不是残余。
  2. 百尔、昆斯泰特等：说的是堕落后仍有的理智和意志，称为“广义形象”（人有别于动物，仍是理性的受造物）。
- Pieper 的判断：两说实质上不矛盾（都承认堕落后人仍有理智和意志，也都承认原始的智慧与义已经丧失），**但推荐路德的读法**。
- 理由：堕落后的理智和意志像“空转的发动机”，认不出救恩（林前2:14），还与上帝为敌（罗8:7），不能因此就称为形象。把创9:6、雅3:9 读成“将在基督里恢复的形象”，还能防止对人性绝望。
- 对笔记里的 5:3：“死的形象”是堕落后亚当传下来的样子，和“狭义形象已丧失”一致。Pieper 的这几节没有专门解释 5:3，这一条是笔记自己的推论。

# 镜头切换的问题

1:1-2 与3 后面的是不是连续镜头这个，好像没有那么清晰。暂倾向于将1:1-2理解为开场镜头（见开头的表，【待定】）。

1:3-2:3是7天创造的结构化叙事

2:4-24是造人的近景镜头。

【补充】

- 如果取读法B（见开头的表），镜头的说法可以改成：**1:1-2 是开场镜头**（从“天地”拉近到“地的初始状态”），1:3-2:3 是逐日的叙事，2:4 起是近景。
- 2:4 的“这是天地被造的来历”（toledoth 公式）是开启新一段的记号，帮助说明 2:4-24 是从 1:26-31 之后“放大”讲造人，而不是另一个互相矛盾的创造记载。

# 安息

1 上帝停下来了，不是需要休息。我们在哪里休息？
2 上帝为人的缘故停下来。（相关经文见下：太3:15“尽诸般的义”、约19:30“成了”）
3 玛拿的故事、安息日、安息在赦罪的福音中（路德的解释）

【补充】

- **1 上帝不是累了**：赛40:28（永不疲倦，也不困乏）；创2:2 是工“完毕”了，才歇；出31:17“歇了工，舒畅爽快”。约5:17 也提醒：“歇了工”不等于不再看顾，“我父做事直到如今”。
- **2 为人的缘故**：可2:27（安息日是为人设立的，人不是为安息日设立的）；申5:12-15（安息的理由是想起你曾是奴隶，耶和华把你领出来）；耶稣替我们“尽诸般的义”（太3:15），十字架上说“成了”（约19:30）；来4:10（进入安息的，乃是歇了自己的工）。
- **3 玛拿与赦罪的福音**：出16:22-30（第六日收双份，第七日不降）——安息是靠神预备，不是靠人赚来；太11:28（凡劳苦担重担的人，可以到我这里来，我就使你们得安息）。路德对第三诫的解释（小教义问答），大意是：我们当敬畏、爱慕上帝，不轻看讲道和他的话语，反要以之为圣，乐意听、乐意学。（这一句我凭记忆写的，仓库里没有找到原文，建议对照你的小教义问答核对。）

# 【待定】问题汇总

1. 1:1-2：总括还是开场？Lawrenz/Jeske 注释取开场（waw 的语法论证），可以把“暂倾向”升级成结论；保留一句“持总括读法的学者的回应，待读”。
2. 光体：“自然节气在大洪水中被摧毁”是推论。8:22 只说地还存留的时候，寒暑昼夜永不停息，没有明说洪水中节气被摧毁，建议标明是推论。
